# Overlay hooks implementation plan

Spec: `docs/specs/2026-10-12-overlay-hooks-design.md`.

**Order:** new machines install `main` directly, so `main` may drop private
settings only after the private layer provides them. The private layer goes
first, and must work with both the old and the new personal repo.

## 1. Private layer (separate repository, draft PR)

- Overlay files:
  - `zshrc`, with the moved shell lines;
  - `pi-settings.json`, generated by the installer, so that local package
    checkouts are listed only when they exist;
  - `claude-settings.json`.
- Owned files: the work tracker config.
- Installer steps:
  1. write the overlay (files at mode 0600);
  2. apply the personal repo;
  3. install the private Pi packages.
- Verify: run the installer's overlay step here. A rendered diff against the
  branch below must be JSON-equal to the snapshot.

## 2. Personal repo (branch `feat/overlay-hooks`, worktree)

Each step is test first, then the change:

1. **zshrc:** source `~/.config/dotfiles-overlay/zshrc` at the end, and drop
   the moved lines. Test: a fake overlay `zshrc` is sourced.
2. **Pi settings:** build the personal settings as data, then merge the
   overlay (`packages` concatenated and de-duplicated, other keys deep-merged).
   Drop the private packages and defaults. Tests: without an overlay, only
   personal entries; with one, the merged result.
3. **Claude settings:** the same merge. The three permission lists are
   concatenated. Private permissions and plugins are dropped. Tests as for Pi.
4. **Install scripts:** keep personal packages only, and reword the plugin
   script comment.
5. **Data flag:** `managedZshrc`, with `work` as a fallback, in
   `.chezmoi.toml.tmpl` and `.chezmoiignore`.
6. **Stop managing the tracker config:** remove it from the source. chezmoi
   leaves the deployed file in place.
7. **Boundary check** in `scripts/check-repository.sh`, with octal-escaped
   identifiers.
8. **Cleanup:**
   - remove the old docs and the unused Neovim plugin files;
   - remove the employer words from the spell file and rebuild `.spl`;
   - move the private README sections out of the README.
9. **Gates:** `npm test` reports `fail 0`, and `npm run check` passes.

## 3. Migration

1. **Mark the private PR ready.** Its bot merges it after CI passes.
2. **Merge the branch to `main`.** Then on this workspace:
   - run the installer's overlay step and `chezmoi apply` (for the reviewed
     targets);
   - check that the rendered files are JSON-equal to the snapshot in
     `~/.local/state/dotfiles-migration-before`.
3. **Mac:** sparse-clone the private layer, then run its installer with
   `managedZshrc = true`. This needs the user's Mac, so the user does it.
