# Add Mosh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provision Mosh alongside the repository's other cross-platform command-line packages.

**Architecture:** Add Mosh to the existing Homebrew bundle, which is consumed by the existing Chezmoi package-install hook on macOS and Linux. No new installer or platform-specific path is needed.

**Tech Stack:** Homebrew Brewfile, Chezmoi, Bash, npm repository tests

## Global Constraints

- Use the existing cross-platform `dot_Brewfile` package mechanism.
- Keep the change limited to Mosh provisioning and its documentation artifacts.
- Verify the exact Brewfile entry and run the repository test suite before committing.

---

### Task 1: Provision Mosh

**Files:**
- Modify: `dot_Brewfile`

**Interfaces:**
- Consumes: `run_onchange_before_01-install-packages.sh.tmpl`, which runs `brew bundle --file="$CHEZMOI_SOURCE_DIR/dot_Brewfile"`.
- Produces: a `brew "mosh"` bundle entry installed by the existing provisioning flow.

- [ ] **Step 1: Verify the package is not already declared**

Run:

```bash
if grep -Fxq 'brew "mosh"' dot_Brewfile; then
  echo "unexpected existing mosh entry" >&2
  exit 1
fi
```

Expected: exit status 0 with no output.

- [ ] **Step 2: Add the minimal package declaration**

Add this line alongside the other terminal packages in `dot_Brewfile`:

```ruby
brew "mosh"
```

- [ ] **Step 3: Verify the exact declaration**

Run:

```bash
test "$(grep -Fxc 'brew "mosh"' dot_Brewfile)" -eq 1
```

Expected: exit status 0.

- [ ] **Step 4: Run repository validation**

Run:

```bash
npm test
npm run typecheck
npm run lint:shell
```

Expected: all commands exit successfully with no test, typecheck, or shell-lint failures.

- [ ] **Step 5: Commit the implementation**

```bash
git add dot_Brewfile
git commit -m "chore: provision mosh"
```

- [ ] **Step 6: Push the branch**

```bash
git push -u origin chore/add-mosh
```

Expected: `origin/chore/add-mosh` is created and tracks the local branch.
